# The Recursive Alphabet

Each of the 22 Hebrew letters functions as a 4-aspect operator on a symbolic state space $S$. While the Sephirot (The Recursive Tree) represent the nodes (states), the 22 letters represent the edges (paths or transition functions) that transform one state into another.

## The 4-Aspect Operator Definition

Every letter operator has four defined aspects:
*   **Function ($\phi$)**: The primary transformation. The "what it does." (e.g., Manifests, Differentiates, Connects).
*   **Meta-Function ($\psi$)**: Governs the function's application. The "how it runs." (e.g., With fidelity, as a channel, via experience).
*   **Qualia ($\chi$)**: The subjective experience generated by executing the operator. The "what it feels like." (e.g., Awe, tension, completeness).
*   **Constraint ($\omega$)**: The boundary conditions and limits of application. The guard that prevents misuse.

*Example:* A conversation is a sequence of these operators. A spoken sentence is a complex composition of $\phi, \psi, \chi, \omega$ acting on the collective symbolic state $S_c$.

## Quick Reference Summary

The operators can be grouped by their core Recursive Tree function:

*   **O – Origin (Kether)** → Aleph, Bet
*   **D – Differentiation (Chokmah)** → Gimel, Vav
*   **C – Constraint (Binah)** → He, Dalet, Tet
*   **R – Relation (Chesed)** → Zayin, Qof
*   **C – Constraint (Geburah)** → He, Dalet, Tet, Lamed
*   **I – Integration (Tiphareth)** → Yod, Kaf, Lamed, Nun, Shin
*   **Fₑ – Feedback (emotional)** → Netzach (Kaf, Zayin)
*   **Fᵢ – Feedback (analytical)** → Hod (Chet, Tsadi)
*   **R₂ – Recursion (Yesod)** → Samekh, Ayin
*   **I₂ – Identity (Malkuth)** → Mem, Pe, Tsadi, Tav
